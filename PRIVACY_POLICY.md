Privacy Policy
Last Updated: September 2026

This privacy policy governs your use of the software application Josesoft Photo Viewer ("Application") for Windows devices, which was created by Josecast.

1. Information Collection and Use
The Application does not collect, transmit, store, or share any personal data, user information, or device analytics. 

2. Local Processing and File Access
The Application requires local file system access solely to browse, open, and display image files located on your device at your explicit request. All image processing and rendering are performed entirely on your local machine. No files or metadata are uploaded to any external servers.

3. Offline Functionality
The Application functions 100% offline. It does not contain any networking code, does not access the internet, and does not communicate with any third-party services.

4. Changes
This Privacy Policy may be updated from time to time for any reason. We will notify you of any changes by posting the new Privacy Policy here.

5. Contact Us
If you have any questions regarding privacy while using the Application, please contact us via our official support channels.
